# GameLog

A social gaming journal: log the games you finish, rate and review them, build
collections, follow other players and discover what the community thinks.

**Status:** under construction. The full setup guide is added once the stack is runnable.

## Stack

- **Web:** Next.js (App Router), React, TypeScript, Tailwind CSS, React Hook Form, Zod
- **API:** ASP.NET Core (.NET 10), C#, Entity Framework Core, PostgreSQL
- **Infra:** Docker Compose, S3-compatible object storage (MinIO in development)

See `docs/` for architecture, database design and the API contract.
