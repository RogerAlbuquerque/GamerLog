# API contract (`/api/v1`)

The complete route list is in [api-reference.md](api-reference.md); this page describes the conventions every
endpoint follows. Interactive documentation: Swagger UI at `/swagger` (Development, or `Swagger:Enabled=true`).

## Conventions

- **Format:** JSON bodies, camelCase properties, enums as strings, ISO 8601 UTC timestamps, UUID identifiers.
- **Pagination:** `?page=1&pageSize=20`; `pageSize` is capped at 50. Responses are `{ items, page, pageSize, total }`.
- **Errors:** RFC 7807 problem documents. `title` is a user-presentable message, `code` is a stable machine-readable
  value (`validation_failed`, `not_found`, `conflict` (some conflicts use a more specific code), `unauthorized`,
  `forbidden`, `provider_unavailable`, `internal_error`, …). Validation problems add an `errors` object keyed by field. Rate limiting answers `429`.
- **Authentication:** cookie `gl.session`, set by `register` and `login`.
- **CSRF:** every `POST`/`PUT`/`PATCH`/`DELETE` needs `X-CSRF-TOKEN`. Get the token from `GET /auth/csrf`; `register`,
  `login`, `logout` and `password` responses carry a fresh one because tokens are bound to the signed-in identity.
- **Repeatable writes:** `PUT` on likes and follows is safe to repeat (the end state is the same). Deleting a
  resource that does not exist answers `404 not_found`.
- **Ratings** are integers in half stars (`1..10`, i.e. 0.5–5 stars).
- **Identifiers** for new rows (diary entries, reviews, …) are generated by the server; the client addresses games
  by `id` in write calls and by `slug` in read calls.

## Visibility and security rules

- Ownership is derived from the authenticated principal, never from the request body.
- Private collections return `404` to everyone except the owner.
- Review and comment bodies are returned as stored; the web client keeps spoiler-flagged text out of the DOM
  until the reader chooses to reveal it (or has enabled "show spoilers by default").
- Deleted comments stay in threads as `{ isDeleted: true }` placeholders without author or body.
- The feed contains the caller's own activity and that of the people they follow; items about reviews that were
  deleted or collections that became private are dropped.
